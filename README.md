# Telegram AI Assistant Bot

An intelligent Telegram assistant built with Python and the Google GenAI SDK. Designed to help students and developers debug code, learn programming concepts, and streamline daily tasks through conversational AI.

---

## 🌟 Key Features

* **AI-Powered Context:** Maintains context during conversations for natural, mentor-like interactions.
* **Code Debugging & Mentorship:** Explains programming errors and offers logical guidance rather than just raw answers.
* **Asynchronous Performance:** Built with `python-telegram-bot` for fast and responsive handling of user queries.

---

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **Framework:** `python-telegram-bot`
* **AI Model:** Google GenAI SDK (Gemini API)
* **Environment Management:** `python-dotenv`
